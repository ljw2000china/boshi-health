# 产品说明 · 薄士 (Boshi)

> 一个"只为一个人"的健康与训练 App。Apple Watch + iPhone，端侧计算，无订阅、无服务器、无广告。

---

## 1. 一句话

把 Apple Watch 上的健康传感器，变成你每天**看得懂、能改、练得明白**的三件事：**恢复得怎样、睡得好不好、今天该不该练、练了什么。**

---

## 2. 对标与定位

| | Athlytic | 薄士 (Boshi) |
|---|---|---|
| 恢复 / 睡眠 / 训练 / 压力 | ✅ 订阅制 | ✅ 免费、端侧 |

**核心理念**：功能尽量无感——手表是快照与一步操作，手机才承担完整编辑；一切推理在本地跑，不需要联网。

---

## 3. 用户旅程

**早晨（手表一瞥）**
点亮手腕，看「今日」：恢复%/睡眠分/训练负荷/压力，一句话结论 + 一条幽默建议。

**白天（自动感知）**
戴上手表正常生活。工作 / 通勤 / 训练都无需主动告诉它——它用运动检测静默识别：练了自动起会话（置信度高直接开始），事后在手机上可改类型或取消；睡了能自动把睡眠窗对齐到真实时段。全程零操作。

**训练时（手表快速记组）**
拿起设备，选动作 → 做一组 → 记重量和次数 → 休息计时自动开。参考上一次同动作的表现，给一条渐进建议。做完了自动写回系统健身记录。

**晚上 / 周末（手机深读）**
看趋势分析（睡眠时长、训练负荷、恢复趋势、ACWR 过载预警）；每周身体地图看哪块练得多/少；睡眠时间轴拖动修正边界；补录漏掉的训练。

## 4. 数据管线（端侧）

```
传感器原始值（心率/HRV/RHR/血氧/Sleep/Workout/Steps/E-Energy）
        │  (HealthKit + WatchConnectivity 双端合并)
        ▼
  数据管线 DataPipeline（actor，30s 缓存）
        │  摄取 → 去重 → 睡眠窗构建（自动修正）→ 逐日评分
        ▼
  基线（恢复/压力/准备度的对照系）→ 恢复/睡眠分/Strain/Stress/SleepDebt/ACWR
        │
        ▼
  SwiftData 持久化 ←→ 手表/手机双向同步（WCSession）
```

- **数据诚实**：只显示真实可推导的值，绝不插值；数据不足时明示"校准中/数据不足" 徽标。
- **阈值提醒**：每日推送 ≤2 条（遵守约束，不打扰）。
- **睡眠写回**：手表端写回 + 4 条安全护栏（版本号 / 来源标记 / 边界校验 / 幂等）。

---

## 5. 主要界面

- **今日（手机）**：恢复环形 + 睡眠分 + 训练负荷 + 压力 + 睡眠债 + 准备度，指标释义卡。
- **健身（手机）**：大横幅（休息日 😴 / 练胸日 💪，点按跑马灯换"薄士-天气"文案）、今日总结、每周身体地图、动作渐进曲线、训练历史（左滑改删）。
- **睡眠 / 健身双页 + 设置**：三页容器 + 自绘胶囊底部导航（保留各页状态、透明可透背景）。
- **设置**：主题（渐变 / 照片墙纸 / 毛玻璃透明度 / 标题字体）、传感器诊断、数据重建。
- **表盘复杂功能**：今日训练表情 + 一句话笑话 + 一周周点。

---

## 6. 设计语言

- 暗色优先 · **毛玻璃（frosted glass）卡片** + 圆角矩形连续曲线
- **Q 弹（springy）按压反馈**，按钮 ≥44pt
- SF Rounded 大号数字 · 中文字体标题胶囊
- 全局渐变 / 照片背景（可在设置切换），卡片透明度用户可调
- 文案走"薄士-天气"：幽默、有梗、不啰嗦；图表留白充足、不拥挤

---

## 8. 隐私声明

所有健康与训练数据**只存于 Apple 设备本地**（HealthKit + App 沙盒），通过 Watch Connectivity 在手表和手机间点对点同步，不经过任何服务器。卸载 App 不丢失系统健康记录；删除 App 即彻底清除其本地派生数据。
