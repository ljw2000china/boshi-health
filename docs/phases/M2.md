# M2 评分引擎 + 概览页

## 范围

设计文档 §9 全部评分公式的 Shared/Scoring/ 实现，手表概览页（3 秒可读）。

## 交付

- `Shared/Scoring/RecoveryScore.swift` — Recovery 公式（zHRV/zRHR/z呼吸/腕温偏移/睡眠效率/精力打卡）
- `Shared/Scoring/StrainScore.swift` — TRIMP（心率区间分钟×权重 + NEAT）→ 21·(1−e^(−TRIMP/K))
- `Shared/Scoring/ACWRScore.swift` — 7d 均值 / 28d 均值，甜区 0.8–1.3，>1.5 告警
- `Shared/Scoring/StressScore.swift` — 日间 HRV 相对夜间基线偏离 + HR 偏离（剔除训练时段），暂做简化版
- `Shared/Scoring/ReadinessScore.swift` — f(Recovery, SleepDebt, 昨日Strain, ACWR, 酸痛打卡) → 0–10
- `Shared/Scoring/SleepDebt.swift` — SleepNeed = 7.5h + 0.3·睡眠债 + 每100TRIMP +5min
- `DataPipeline.updateDailyMetric` 扩展：写入 recovery / strain / acwr / stress / readiness / sleepNeed / sleepDebt
- `WatchPulse/OverviewView.swift` — 今日概览（Recovery 大字 + 次要卡片：睡眠分/Strain/ACWR/状态徽标）
- 手机端 OverviewView 复用，接入 ContentView
