# M3 打卡 + 晨间报告

## 范围

每日精力/酸痛打卡（1–5），晨间报告（睡眠窗锁定后一次性本地通知），打卡进入 Recovery 计算。

## 交付

- `Shared/Store/PulseModels.swift` — DailyMetric 增 energy/soreness（已加），打卡写入接口
- `Shared/Checkin/CheckinService.swift` — 读写今日打卡（1–5），触发评分重算
- `Shared/UI/CheckinView.swift` — 双端打卡 UI（手表 2 次点击完成：精力→酸痛）
- `Shared/Notify/MorningReport.swift` — 本地通知（UNUserNotificationCenter），每日最多 1 条
- `WatchPulse`/`PhonePulse` 接入（打卡入口 + 通知授权）
- 单测：打卡幂等、通知内容生成

## 约束

- design.md §11：默认通知 ≤2 条/天；晨间报告 1 条（窗锁定后）
- 打卡可跳过，不强制；未打卡时 Recovery 打卡项按中性处理（已有实现）

## 验证

- 单测全绿 + 双端 typecheck 0 错误
