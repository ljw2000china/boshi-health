# M4 训练自动检测

## 范围
design.md §7：10min 滚动窗信号融合 → 置信度 → 静默起会话/询问/忽略；类型推断；结束检测；HKWorkout 写回。

## 交付
- `Shared/Workout/WorkoutDetector.swift` — 滚动窗信号聚合 + 置信度计算 + 类型推断（纯函数，可单测）
- `Shared/Workout/WorkoutSession.swift` — 会话状态机（idle/detected/active/ending/ended）
- `Shared/Workout/WorkoutWriter.swift` — HKWorkout 写回（source metadata=Pulse:auto）
- `WatchPulse/WorkoutMonitor.swift` — 后台 HR/能量采集驱动检测器
- 单测 ≥6（信号阈值、置信度档位、类型推断、结束条件）

## 非范围
M5 组次记录 UI；M6 训练分析
