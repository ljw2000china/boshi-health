# 代码评审清单（code-checklist）

代码评审逐项核查表。每项必须给出证据（文件:行）。

## 1. 功能正确性
- [ ] 阶段规格承诺的逻辑全部真实实现（无桩代码冒充）
- [ ] 边界条件：空数据 / 未授权 / 充电中 / 手表未佩戴 / iPhone 断连
- [ ] 时区与日期边界（跨午夜窗口、夏令时）

## 2. HealthKit 使用
- [ ] 类型标识符正确（quantity/category 不混用）
- [ ] 增量查询（HKAnchoredObjectQuery / 日期谓词），无全量拉取
- [ ] 授权请求最小化，且拒绝授权后有降级 UI
- [ ] 后台交付频率声明合理（hourly 为主，无 .immediate 滥用）

## 3. 后台行为
- [ ] 无高频 NSTimer/轮询；无循环唤醒风险
- [ ] WorkoutSession 生命周期完整（start/pause/end + 系统打断恢复）
- [ ] 扩展运行时/后台交付的失效场景有兜底

## 4. 资源开销
- [ ] CPU：无主线程重计算；聚合批量执行
- [ ] 内存：原始序列缓存有上限与淘汰策略
- [ ] 存储：SwiftData 90 天后降采样策略存在
- [ ] 电量：采样/唤醒频率符合 PLAN 预算；充电时停止判定

## 5. 算法
- [ ] 与 docs/design.md 的公式/权重一致
- [ ] 数值稳定：除零、空窗口、NaN 防护
- [ ] 复杂度 ≤ O(n)；有增量计算或缓存复用
- [ ] 有优化空间时给出具体建议

## 6. 数据安全
- [ ] 每次写入带来源标记（system/extended/override/auto/manual/native）
- [ ] 覆盖逻辑可回滚（保留原始值与版本号）
- [ ] 无数据丢失路径（写入失败有重试或暂存）

## 7. 构建与结构
- [ ] xcodebuild 通过（模拟器目标）
- [ ] Target 划分合理；Shared 包无 UI 依赖倒置
- [ ] 免费证书约束遵守：无 App Groups、无推送、无 iCloud
- [ ] 无网络请求、无第三方追踪 SDK
