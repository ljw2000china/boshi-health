# 开发历程 · 薄士 (Boshi)

> 从"想法"到"能用的双端健康训练 App"的记录。每个阶段都有可运行的交付物、通过的自测与评审。

---

## 0. 项目由来

个人想有一个 **Apple Watch S9 + iPhone** 的健康/训练监测工具,对标 Athlytic,但:
- 不开订阅、不要云端、数据全在本地;
- 更懂力量训练(组次系统、身体地图、渐进曲线);
- 更省心(训练自动开始、睡眠自动对齐);
- 文案有梗不无聊。

最终做成了自用的「薄士」——一个只服务一个人的端侧计算 App。

## 2026-11-06 · 毛玻璃 Q 弹卡片 + 背景穿透根因

- 卡片重写 `.ultraThinMaterial` + 高光渐变 + 渐变描边 + 弹簧按压缩放。
- **背景不生效两个根因**(模拟器逐层像素验证):
  1. `ThemeStore` 用 `@AppStorage` 在 ObservableObject 里**不触发 objectWillChange** → 改 `@Published` + `didSet` 手写 UserDefaults;
  2. `NavigationStack` 自带**不透明底层** → 背景铺进每个页面 ScrollView 的 `themedSurface()`;
  3. 自定义**底部毛玻璃胶囊导航**替换 TabView(避开 UITabBarController 不透明层,三页并存保状态)。
- **空指标根因**:基线只在手动刷新时建 → 启动补 `rebuildBaseline()`;趋势页空态自动补建。
- 指标释义卡、watchOS 根注入 theme。**104/104**。
